# Pro reports

* **Show Security Review**: server_tokens, outdated TLS versions, missing Strict-Transport-Security, directory listings and add_header inheritance.
* **Show Proxy And Upstreams**: Upstreams with their members, and every proxied location with its target and whether it passes the Host and X-Forwarded-For headers.

The first Pro command starts a free 14-day trial on this computer. After the trial, Pro is a one-time purchase: USD 19 (Personal) or USD 39 per user (Business).
